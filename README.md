# ViperAura Studio 5.0

AI-Assisted Network Exposure Assessment Platform

## Overview

ViperAura Studio 5.0 is a cybersecurity assessment platform developed in a Kali Linux environment. The tool helps identify network exposure risks through automated scanning, service enumeration, vulnerability research, historical comparison, and report generation.

The project was created to provide security analysts with an organized workflow for conducting authorized security assessments and documenting findings.

---

## Features

- Multiple scanning modes (Turbo, Smart, Deep)
- Network host discovery
- Service and version detection
- Historical scan comparison
- SQLite database storage
- PDF report generation
- Streamlit dashboard interface
- Optional CVE/NVD vulnerability research
- AI-assisted security explanations
